日期：2026-10-16。用户已确认 UI 方案，本次仅完成该范围；阶段 B–E 保持暂停。

## 实际改造

- 参考用户截图的灰紫画布、白色圆角卡片与蓝紫重点色，统一工作台、人才/职位/公司列表、详情、表单、附件及登录。
- 外框采用容器网格与独立内容滚动；桌面侧栏可收缩，小屏使用支持焦点管理的 Element Plus 抽屉。路由跳转重置内容滚动，详情导航保持选中状态。
- 首页使用现有 API 展示四项实际数量、最近更新的人才、在招职位；保留真实空态、加载与错误恢复，不生成无依据的图表或增长率。
- 使用原有 Pure Admin、Pinia、路由权限数据与 Element Plus，没有新增依赖。旧模板布局/设置文件保留，新界面只开放已适配的浅色纵向导航。
- 显示偏好迁移版本为 `hunter-ui-version = lavender-1`，仅更新布局与界面偏好；保留无关存储与账号资料，不清空 localStorage。
- 手机表单单列、触控目标约 44 px、输入至少 16 px；表格使用内部横向滚动。日期面板在两侧空间均不足时可沿两个方向移入视口，并限制最大高度，底部确认按钮可见。
- 主题集中在 `frontend/src/style/hunter-theme.scss`；业务排版在 `frontend/src/views/hunter/style.scss`；日期定位参数在 `frontend/src/views/hunter/ui.ts`。后续页面可复用。
