- 仅维护电脑浏览器；默认覆盖宽度 1024、1280、1440、1920 px，主截图 1440 px。1024 px 用于电脑窄窗口；不作为平板支持声明。
- 保留窗口缩放后的布局、桌面侧栏展开/收起及偏好恢复、长文本换行、表格局部滚动、键盘和浏览器缩放。
- 除常规窗口外，增加 1280 × 720 的桌面较矮窗口检查，保证编辑弹窗、日期/时间控件和底部操作可到达。
- 不再要求手机和平板专用布局及验收；不增加手机提示页，不按设备拦截访问。
