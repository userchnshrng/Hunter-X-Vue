# 候选人导入模板兼容

## 变更范围

用户要求将工作台空模板改为其候选人记录表的格式。已只读核对结构：工作表“候选人”，第 1 行空白，第 2 行表头；依次为日期、姓名、公司、职位、联系电话、记录、链接。列宽及换行方式参考该表，模板不复制实际候选人、批注、隐藏资料或原文件属性。

实现约定：

- 默认下载改为 XLSX 空模板，保留上述七列和第二行表头，不增加示例人才或说明行。
- 自动建议表头行和列映射，兼容原七字段 CSV 及其他已有自定义列。
- 日期接受明确的 `YYYY.MM.DD`，原表空日期保持空，不沿用上一行或猜测年份。
- 联系电话映射为电话，记录映射为历史沟通，未知沟通时间保持空。
- 链接映射到固定“简历链接”附加字段 `resume_link`，允许 2,000 字；复用已有 JSON 存储，不增加 schema、不执行数据迁移。固定字段不能在定义管理中改类型或停用。
- Excel 超链接保留实际目标地址，优先用于“简历链接”；其他字段保留显示文字。只读取链接，不访问外部页面；详情仅为 HTTP(S) 地址提供可点击入口。
- 数字电话仍提示核对，缺姓名行仍报错；不以改模板为由静默跳过或修改原数据。
- 本次不上传原表到开发服务或测试库，不提交真实人才。测试使用独立生成的合成记录。
